# 몽글숲 마을 (Mongle Village)

동물 친구들과 함께 농사짓고 마을을 키우는 힐링 마을 게임.
설계는 `../1단계_설계문서.md` 참고.

## 언어 (한국어 / 日本語)
- 타이틀 오른쪽 위 🇰🇷 / 🇯🇵 국기를 누르면 바로 바뀜. 게임 안에서는 설정 → 언어
- 고른 언어는 기기마다 기억함. 처음엔 브라우저 언어(일본어면 일본어)로 시작
- 글자: `src/data/i18n/ko.js`(한국어), `src/data/i18n/ja.js`(일본어). 같은 키에 글만 바꾸면 됨
- 일본어 글꼴은 M PLUS Rounded 1c (구글 폰트)

## 5단계 건설 (완료)
- 🔨 건설 메뉴: 창고(가방 +10칸/레벨), 울타리(옆과 저절로 이어짐), 길(징검돌 → 벽돌 → 꽃길), 꽃밭(가로·세로 돌리기)
- 잠긴 건물(광장, 잡화점, 빵집, 분수, 공방)은 몇 등급에서 열리는지 미리 보여줌 (등급은 7단계)
- 놓기 모드: 초록 칸 = 놓을 수 있음, 빨강 = 못 놓음(이유 표시). 땅을 누르거나 끌어서 자리 고르기, 키보드 방향키·R·Enter·Esc
- 길을 막아서 밭이나 건물에 못 가게 되는 자리는 막아줌
- 건물을 길게 누르면 건물 창: 업그레이드(Lv1→5), 옮기기, 치우기(꾸미기, 재료 돌려받음), 공사 취소(재료 모두 돌려받음)
- 공사는 현실 시간 (꺼놔도 진행), 일꾼 2명이라 동시에 2개까지. 도도가 촌장이면 10% 빨리
- 완성 연출: 공사 틀이 퐁 사라지고 반짝이 + 효과음 + 가까운 주민이 축하
- 마을회관 업그레이드 = 작물 판매가 +5%/레벨
- 나무·바위를 누르면 나무·돌을 얻음 (하나당 하루 한 번, 다음 날 다시 생김)
- 안내 이어짐: 팔기 → 재료 모으기 → 창고 짓기 → 완성
- 건설 규칙은 `src/core/build.js`, 건물 숫자(비용·시간)는 `src/data/buildings.js`, 그림은 `src/view/buildingArt.js`

## 4단계 저장 (완료)
- 자동 저장: 무언가 바뀌면 1초 뒤, 30초마다, 화면을 떠날 때 (IndexedDB + localStorage 예비)
- 타이틀에서 이어하기 / 새 마을 만들기 (새로 만들면 경고 표시)
- 꺼둔 사이에도 작물이 자람 → 돌아오면 "다녀왔어요!" 요약
- 설정: 소리, 지금 저장, 파일로 내보내기, 백업 코드 복사, 파일·코드로 불러오기, 처음부터 (두 번 눌러야 지워짐)
- 저장은 `src/services/SaveService.js` 한 곳에서만. 구조가 바뀌면 `migrations.js`에 변환 추가

## 3단계 농사 (완료)
- 밭 6칸: 누르면 캐릭터가 걸어가서 알아서 심기 → 물주기 → 수확
- 작물 10종, 씨앗 → 새싹 → 다 자람, 단계마다 물 필요 (안 줘도 죽지 않고 기다림)
- 현실 시간으로 자람, 제철이 아니면 2배 느림, 촌장 보너스(모모 채소, 나리 꽃 10% 빠름)
- 가방(30칸), 마을회관 씨앗 가게, 출하함(작물 팔기), 처음 안내 문구, 효과음
- 농사 규칙은 `src/core/farm.js`, 작물 숫자는 `src/data/crops.js`

## 2단계 뼈대 (완료)
- 타이틀에서 촌장 고르기 + 마을 이름 짓기
- 40×28칸 타일 마을 (풀밭, 흙길, 강, 연못, 나무, 바위, 꽃, 마을회관)
- 캐릭터 이동: 화면 탭/클릭 → 길을 찾아 걸어감, 키보드 WASD·방향키
- 카메라: 끌어서 이동, 두 손가락·마우스 휠·＋/－ 버튼으로 확대/축소, 🎯로 내 캐릭터에게
- 주민을 누르면 말버릇 말풍선 + 기쁨 반응 (나리·보리는 포즈 그림 사용)
- 현실 시각에 맞춘 낮/밤 색, 7일마다 바뀌는 계절 표시
- 아래 메뉴 버튼은 몇 단계에서 열리는지 알려줌

## 실행 방법
**가장 쉬운 방법**: 공개 주소 https://joongyub.github.io/mongle-survivors/village/ 열기 (누구나 접속 가능, 저장은 각자 기기에).

**내 컴퓨터에서 직접 열기**: 이 폴더의 `index.html`을 더블클릭하면 안 돼 (브라우저가 보안 때문에 일부 파일을 막음).
작은 "로컬 서버"로 열어야 해. 가장 쉬운 방법은 VS Code의 Live Server:
1. VS Code를 설치하고 실행
2. 왼쪽 맨 아래 네모 4개 아이콘(확장) 클릭 → 검색창에 `Live Server` → **설치**
3. 메뉴 **파일 → 폴더 열기** → 이 `mongle-village` 폴더 선택
4. 왼쪽 파일 목록에서 `index.html`을 오른쪽 클릭 → **Open with Live Server**
5. 브라우저가 열리며 게임이 시작됨

## 폴더 구조
```
index.html          게임 첫 페이지
css/ui.css          메뉴·버튼 디자인
lib/phaser.min.js   Phaser 3.90 엔진 (그대로 둠)
art/characters/     주민 그림 (포즈 그림은 아이디 폴더 안에)
src/main.js         시작점
src/core/           게임 규칙 (화면과 분리된 순수 함수): clock.js 시간, grid.js 길찾기, farm.js 농사, build.js 건설
src/data/           지도, 주민, 그림 경로, 글자(i18n)
src/state/          게임 상태
src/services/       저장 (SaveService, LocalStore, migrations)
src/scenes/         Phaser 화면 (Boot, Village)
src/view/           코드로 그린 그림, 캐릭터, 카메라
src/ui/             HTML 메뉴 (타이틀, HUD, 알림)
build_artifact.py   Claude 미리보기용 artifact.html 만들기
```

## 자주 고칠 곳
- 지도 모양: `src/data/map.js`의 글자 줄
- 주민 이름·말버릇: `src/data/residents.js`
- 화면 글자: `src/data/i18n/ko.js` (일본어 `ja.js`)
- 건물 비용·시간·효과: `src/data/buildings.js`
- 포즈 그림 추가: `art/characters/<아이디>/happy.png` 등을 넣고 `src/data/assets.js`의 `POSE_IMAGES`에 한 줄 추가
