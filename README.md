# 몽글숲 서바이버즈

동물의숲 감성의 뱀서라이크 2D 도트 게임. 빌드 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.

## 파일 구조
| 파일 | 내용 |
|---|---|
| `index.html` | 화면 레이아웃·스타일(메뉴, 카드, 결과창), 스크립트 로드 순서 |
| `js/sprites.js` | 모든 도트 그래픽을 코드로 생성 (캐릭터 10, 적 10, 무기/아이템 아이콘, 배경 장식). 새 에셋은 여기에 그리기 함수 추가 |
| `js/data.js` | 밸런스/콘텐츠 데이터: 캐릭터, 무기(레벨별 강화), 진화, 패시브, 적, 웨이브, 보스, 이벤트, 벨 상점 |
| `js/audio.js` | WebAudio로 합성한 효과음과 배경음악 |
| `js/game.js` | 전투 엔진: 이동, 무기 발사, 충돌(공간 분할), 경험치, 보스 AI, 렌더링, HUD |
| `js/i18n.js` | 언어 설정(한국어/日本語). UI 문구 사전과 데이터 번역. 새 문구는 ko/ja 양쪽에 추가 |
| `js/ui.js` | 타이틀/캐릭터 선택/레벨업/보물상자/일시정지/결과/상점 화면, 키보드·터치 조이스틱, 16:9 스케일 |
| `build_artifact.py` | `index.html`을 아티팩트 게시용 `artifact.html`로 변환 |

## 핵심 시스템
- 15분 생존 + 5분/10분/15분 보스(여왕말벌 → 대왕 멧돼지 → 밤의 늑대왕). 최종 보스 처치 시 클리어.
- 무기 10종(최대 Lv7) + 패시브 10종(최대 Lv5, 체리는 2). 무기 최대 레벨 + 짝 패시브 보유 상태에서 보물상자(엘리트 심술곰/보스 드랍)를 열면 진화.
- 레벨당 모든 공격력 +5% → 데미지 숫자가 수십에서 수천까지 커짐. 숫자 크기·색이 데미지 크기에 따라 변함.
- 모든 무기는 가까운 적을 자동 조준하고 쿨타임이 짧아 쉬지 않고 공격. 같은 적을 연타하면 데미지 숫자가 누적되어 커지고, 처치 콤보 카운터가 표시됨.
- 모바일 조이스틱은 오른쪽 아래 고정.
- 벨(영구 재화)로 상점에서 영구 강화. 저장은 localStorage(`mongle-survivors-v1`).

## 진화 조합
뿅망치+힘의 사과 · 잠자리채+꽃 화분 · 낚싯대+네잎클로버 · 조개 부메랑+쌍둥이 체리 · 도토리 새총+종소리 시계 · 꽃삽+단단한 조개 · 꿀단지+자석 소라 · 별님 지팡이+별사탕 · 튤립+바람 깃털 · 숟가락+하트 쿠키

## 테스트
브라우저 콘솔에서 `G.debug` 사용: `G.debug.xp(100)`, `G.debug.skip(290)`(보스 직전), `G.debug.maxAll()`, `G.debug.chest()`, `G.debug.god()`, `G.game.autopilot = true; G.game.speed = 8`(자동 플레이 고속).
